# API

1. Clonar proyecto
2. Instalar dependencias
   ```
   npm i
   ```
3. Clonar el archivo : .env.template y renombrarlo a .env
4. levantar bd:

```
docker-compose up -d
```

5. Levantar API:

```
npm run start:dev
```
