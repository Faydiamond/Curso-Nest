# Ejecutar en desarrollo

1. Clonar repositorio
2. Ejecutar

```
yarn install
```

3. Disponer de nest cli instalado

```
npm i -g @nestjs/cli
```

4. Levantar la bd

```
docker-compose up -d
```

5. Resulta importante tener instalado docker en el equipo y que adicionalemnte este ejecutandose.

## Stack usado

- MongoDb
- Nest
- Docker
